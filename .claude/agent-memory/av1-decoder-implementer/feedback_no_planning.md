name: No Planning Phase
description: User prefers direct implementation execution without planning/alignment phases
type: feedback
---

Skip planning phases and go straight to implementation. Do not ask for alignment or confirmation before starting work.

**Why:** User prefers action over discussion. They trust the agent to make reasonable implementation choices.

**How to apply:** When given a task, start implementing immediately. Only ask clarifying questions if genuinely blocked (e.g., ambiguous requirements with no reasonable default).
