av1go is a pure Go AV1 encoder/decoder project. Module name is `av1go`, Go 1.26.1, zero external dependencies.

**Why:** Educational/production AV1 implementation in Go with no cgo dependencies.

**How to apply:** All code must be pure Go. Use spec-aligned naming from the AV1 spec. The project has both encoder and decoder components being built incrementally.
